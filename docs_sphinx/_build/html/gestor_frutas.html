class gestor_frutas.Fruta[código fonte]¶

Bases: object

Representa uma fruta registada no estoque.

Parâmetros:

  • id_fruta (int) – ID numérico único da fruta.

  • tipo (str) – Nome da fruta (ex: Maçã, Laranja).

  • especie (str) – Variedade da fruta (ex: Gala, Fuji).

  • peso (float) – Quantidade em estoque (kg).

class gestor_frutas.GestorFrutasBase[código fonte]¶

Bases: object

Esta classe mostra a grelha de frutas quando o programa é executado e é a primeira coisa que o utilizador ver.

Quando uma fruta é criada, esta recebe um ID para a identificar

Parâmetros:

  • frutas (list) – É a lista que guarda as frutas

  • proximo_id (int) – É o organizador de IDs em que a primeira fruta começa com o ID 1

adicionar_fruta()[código fonte]¶

Esta função adiciona as frutas com os seus atributos Primeiro se insere o tipo, de seguida a espécie e peso

Aviso

O peso não pode ser e inferior e igual a zero

Retorno:

fruta e ID

Tipo de retorno:

string e inteiro

apagar_fruta()[código fonte]¶
atualizar_fruta()[código fonte]¶

Esta função atualiza os atributos de uma fruta existente atraves da inserção do ID

Aviso

Vai aparecer um sinal de aviso caso for pressionar «Enter» se o campo ainda estiver vazio e se o id for inválido

Retorno:

ID, tipo, espécie e peso atualizados

Tipo de retorno:

strings, floats e inteiro

mostrar_grelha()[código fonte]¶

Esta função faz construção real da grelha de frutas e pocisionamento de cada atributo da fruta, onde mostra o ID, tipo, espécie e peso da fruta.

Nota

Se não houver nenhuma fruta registada no stock mostra uma mensagem de aviso

Retorno:

A grelha

Tipo de retorno:

strings, floats e inteiros

ver_fruta()[código fonte]¶
Esta função faz que o utilizador possa consultar

a fruta inserida recentemente atraves do ID inserido

Nota

Se não houver nenhuma fruta registada no stock e id invalido mostra uma mensagem de aviso

Retorno:

ID, tipo, espécie e peso

Tipo de retorno:

strings, floats e inteiros
