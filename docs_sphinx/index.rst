Sistema de Gestão de Frutas e Vendas
====================================

Bem-vindo à documentação técnica oficial do projeto **Gestor de Frutas**,
desenvolvido no âmbito da unidade curricular de **Ambientes de Desenvolvimento Colaborativo** (CTeSP).

Esta aplicação, desenvolvida em Python sob o paradigma de Programação Orientada a Objetos,
permite gerir o inventário de frutas em stock por peso (kg), disponibilizando operações
para registar, listar, consultar, editar e remover frutas, bem como processar pedidos
de venda e associar os dados dos respetivos clientes.
